# Recording the flow

TourD needs to know **what a user does**, in order, to decide which controls get a step. Four ways to tell it, all in
the project's **Recordings** tab. "Auto-detect" picks the format; you can also choose it.

| Format | Best for | Effort |
| --- | --- | --- |
| **TourD recorder** (browser extension) | the best case: exact controls, views and controllers from UI5 itself - see [EXTENSION.md](EXTENSION.md) | lowest |
| Chrome DevTools Recorder (JSON) | when you cannot install the extension: click through the app once | low |
| UI5 Test Recorder (OPA5 or wdi5 code) | when you already record tests, or the DOM is hard to read | low |
| Plain text | a quick draft, or when you cannot run the app | write one action per line |

A recording made with the extension can also hold **checks** ("Add a check"): what a control showed when you pointed at it. They become checks in the wdi5 tests ([WDI5.md](WDI5.md)) and are ignored by tours.

Tour steps come from **clicks and changes**; scrolling, hovering and viewport changes are ignored. Typed values are
never sent to an AI provider.

## Chrome DevTools Recorder

1. Open your app in Chrome or Edge. Press **F12**, open the **Recorder** panel (under the **⋮ / More tools** menu if you do not
   see it).
2. **Create a new recording**, give it a name, **Start recording**.
3. Do the flow you want to explain, **in the order a new user should learn it**: open the list, press *Create*,
   fill the first field, press *Save*. Do not wander: every click may become a step.
4. **End recording**. Use **Export** and pick **JSON**.
5. In TourD: project → **Recordings** → **Import recording**, choose the file (or paste it), and say what it is for: **Tour**, **Tests** or **Tour and tests** (a file does not say, so the default is both; a recording from the extension says it itself). Generating a tour offers the recordings for tours, making tests offers those for tests; the label can be changed in the list.

TourD finds the UI5 control behind each recorded element: it removes the suffixes UI5 adds to inner DOM elements
(`-inner`, `-content`, `-img`, …) and looks for the control id inside your views. The import shows every recorded step with
the control it was matched to; steps that could not be matched are marked and can be fixed in the editor.

Tips

- Names like `__button3` or `__xmlview0--__item0-…` are generated by UI5 and change from run to run. Give the control
  an `id` in the view (see [Troubleshooting](TROUBLESHOOTING.md)) and record again.
- Record against the same version of the app as the files you uploaded; otherwise ids will not match.

## UI5 Test Recorder (OPA5 or wdi5)

1. Open your app. Press **Ctrl + Alt + Shift + S** (the *Technical Information* dialog) and choose **Open Test Recorder**.
2. In the recorder, press **Start recording**, use the app, and select the actions you want (press, enter text, …). The
   recorder shows the code for each one.
3. Copy the code of the actions as **OPA5** or **wdi5** and paste it into TourD (**Recordings** → paste, format
   *UI5 Test Recorder*). Pieces such as `new Press({ id: "createBtn", viewName: "my.app.view.Main" })` carry the view name and control id,
   so they map 1:1.

## Plain text

One action per line, with or without numbers, for example:

```
1. Search for Acme in the search field
2. Click Create
3. Enter "Acme Corp" in Customer
4. Select the status
5. Click Save
Remember to mention that saving returns to the list.
```

Verbs such as click, press, open, choose, select (a step), enter, type, fill in (a value), search for, and
"go to <route>" are understood; anything else becomes a note the AI generator can use as context. The words after the verb
are matched against the control texts, labels and ids of your app. Useful to sketch a tour without recording.

## What the import tells you

- *N of M matched*: how many recorded steps were linked to a control of your files.
- Steps without a match stay in the recording but become steps "that need a control" when you generate; the export is
  blocked until they are fixed (or you choose to download anyway).
